# Maple Lie Detector (MVP)

메이플스토리 화면을 공유하고 OCR 텍스트에서 `거짓말 탐지기` 문구를 찾아 알림음을 재생하는 브라우저 도구입니다.

## 실행
```bash
npm install
npm run dev
```
Vite가 출력하는 주소(일반적으로 http://localhost:5173)를 Chrome / Edge에서 엽니다.

## 동작
- 화면 공유: `getDisplayMedia`
- 한국어/영어 OCR: Tesseract.js (`kor+eng`)
- 감지 주기: 설정 UI (화면 공유 중에는 변경 비활성화)
- 알림음: Web Audio API
- 중복 방지: 같은 문구가 유지될 때 10초 cooldown
- 자동 입력/문제 풀이 없음

## 주의 / 개선점
- 첫 실행 때 한국어 OCR 모델을 다운로드하므로 네트워크가 필요합니다.
- OCR은 게임 이펙트, 글꼴, UI 배율, 해상도에 따라 누락될 수 있습니다.
- 현재 OCR 영역은 공유 화면 중앙 58% 영역으로 제한했습니다. 실제 게임 캡처에서 문구가 나타나는 영역에 맞춰 ROI를 조정해야 합니다.
- 팝업에 문구가 정확히 나오지 않는 변형은 별도 이미지/패턴 감지로 보완할 수 있습니다.
- Chrome/Edge에서 화면 공유 권한을 허용하세요. 알림음은 테스트 버튼으로 브라우저 오디오 동작을 확인할 수 있습니다.
